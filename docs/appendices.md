## APPENDIX A: Centralized API Directory

The following table documents the core API routes used to connect the React frontend with the Node.js backend.

| Method | Endpoint | Headers Required | Authentication | Purpose |
| :--- | :--- | :--- | :---: | :--- |
| `POST` | `/api/auth/signup` | `Content-Type: application/json` | None | Registers a new user. Supports optional parent referral code linking. |
| `POST` | `/api/auth/login` | `Content-Type: application/json` | None | Authenticates credentials and returns a secure JWT. |
| `GET` | `/api/auth/user` | `x-auth-token: {{authToken}}` | Customer | Fetches active profile data, wallets, and downline metrics. |
| `POST` | `/api/user/address` | `x-auth-token: {{authToken}}` | Customer | Appends a new delivery address card to the user document. |
| `GET` | `/api/shop/products` | None | None | Queries catalog items with price filters, categories, and search strings. |
| `POST` | `/api/payment/create-order`| `x-auth-token: {{authToken}}` | Customer | Contacts Razorpay to generate a transaction order ID. |
| `POST` | `/api/payment/verify` | `x-auth-token: {{authToken}}` | Customer | Verifies digital signatures and processes two-tier payouts. |
| `POST` | `/api/payment/withdraw` | `x-auth-token: {{authToken}}` | Customer | Exchanges accumulated wallet balance for digital gift vouchers. |
| `GET` | `/api/admin/users` | `x-auth-token: {{adminToken}}` | Admin | Retrieves the full platform user directory and referral lineages. |
| `POST` | `/api/admin/products` | `x-auth-token: {{adminToken}}` | Admin | Adds a new product to the storefront, specifying its pricing and commission rate. |

## APPENDIX B: Core Database Schema Blueprints

The dynamic referral linkages and commission transactions are powered by two primary schemas in the MongoDB database:

### 1. User Schema Model
Represents user records, downline lists, wallets, and withdrawal records.
```javascript
const mongoose = require('mongoose');

const UserSchema = new mongoose.Schema({
    email: { type: String, required: true, unique: true },
    password: { type: String, required: true },
    phone: { type: String, required: true },
    referralCode: { type: String, unique: true }, // Dynamic unique code
    referredBy: { type: mongoose.Schema.Types.ObjectId, ref: 'User' }, // Parent node
    directReferrals: [{ type: mongoose.Schema.Types.ObjectId, ref: 'User' }], // Level 1 (Max: 8)
    wallet: { type: Number, default: 0 }, // Wallet commission balance
    earnings: {
        direct: { type: Number, default: 0 },   // Level 1 commission total
        indirect: { type: Number, default: 0 }, // Level 2 commission total
        total: { type: Number, default: 0 }     // Combined commission total
    },
    addresses: [{
        name: String,
        line1: String,
        city: String,
        state: String,
        zipCode: String,
        phone: String,
        isDefault: { type: Boolean, default: false }
    }],
    withdrawalHistory: [{
        amount: Number,
        brand: String, // e.g., Amazon, Flipkart
        couponCode: String,
        date: { type: Date, default: Date.now }
    }]
}, { timestamps: true });

module.exports = mongoose.model('User', UserSchema);
```

### 2. Order Schema Model
Tracks checkout records, buyer links, payment details, and shipping statuses.
```javascript
const mongoose = require('mongoose');

const OrderSchema = new mongoose.Schema({
    user: { type: mongoose.Schema.Types.ObjectId, ref: 'User', required: true },
    items: [{
        product: { type: mongoose.Schema.Types.ObjectId, ref: 'Product', required: true },
        quantity: { type: Number, required: true },
        price: { type: Number, required: true },
        name: { type: String, required: true }
    }],
    totalAmount: { type: Number, required: true },
    paymentInfo: {
        paymentId: { type: String }, // Razorpay Payment ID
        orderId: { type: String, required: true }, // Razorpay Order ID
        signature: { type: String },
        method: { type: String, required: true } // 'Razorpay' or 'Wallet'
    },
    shippingAddress: {
        name: String,
        line1: String,
        city: String,
        state: String,
        zipCode: String,
        phone: String
    },
    status: {
        type: String,
        enum: ['Confirmed', 'Processing', 'Delivering', 'Delivered'],
        default: 'Confirmed'
    }
}, { timestamps: true });

module.exports = mongoose.model('Order', OrderSchema);
```

## APPENDIX C: Signature Verification Utility Script

This Express backend controller script validates payment legitimacy using the Node.js crypto library to verify the HMAC-SHA256 signature generated by Razorpay.

```javascript
const crypto = require('crypto');

/**
 * Validates signature received from Razorpay sandbox
 * @param {string} orderId - The Razorpay Order ID
 * @param {string} paymentId - The Razorpay Payment ID
 * @param {string} signature - The HMAC-SHA256 signature to verify
 * @returns {boolean} True if the signature matches, false otherwise
 */
function verifyPaymentSignature(orderId, paymentId, signature) {
    const keySecret = process.env.RAZORPAY_KEY_SECRET;
    
    if (!keySecret) {
        throw new Error("Missing RAZORPAY_KEY_SECRET environment variable.");
    }
    
    // Generate HMAC hash payload by joining parameters with a pipe character
    const hashPayload = orderId + "|" + paymentId;
    
    // Create HMAC SHA256 cipher using the Razorpay secret key
    const calculatedSignature = crypto
        .createHmac('sha256', keySecret)
        .update(hashPayload)
        .digest('hex');
        
    // Validate if the generated hash matches the signature parameter
    return calculatedSignature === signature;
}
```
