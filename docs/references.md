# REFERENCES & BIBLIOGRAPHY

This section lists the official documentations, dynamic web resources, online tutorials, and industrial practice guidelines consulted during the research, design, and implementation of the **Referral E-Commerce System**.

---

## 1. Official Documentation & Reference Portals
*   **React Official Documentation**: [https://react.dev](https://react.dev) (Consulted for state management hooks, dynamic context routing, and storefront component cycles).
*   **Node.js Runtime Documentation**: [https://nodejs.org/docs](https://nodejs.org/docs) (Consulted for backend runtime structures and asynchronous execution models).
*   **Express.js Framework Guide**: [https://expressjs.com](https://expressjs.com) (Used for middleware validation triggers, secure endpoint routing, and request handling).
*   **Mongoose ODM Reference Manual**: [https://mongoosejs.com/docs](https://mongoosejs.com/docs) (Used for Mongoose schema designs, validation rules, and atomic database increments).
*   **Razorpay Developer Hub**: [https://razorpay.com/docs](https://razorpay.com/docs) (Consulted for transaction workflows, sandbox signatures, and API parameters).
*   **MDN Web Docs**: [https://developer.mozilla.org](https://developer.mozilla.org) (Used for responsive CSS grid/flexbox properties and client session storage guidelines).
